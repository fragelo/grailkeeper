Help & Reference

Token Setup

Go to Settings → enter your environment URL and a Platform Token (dt0s16.xxx).

Required scopes: storage:logs:read storage:events:read storage:metrics:read storage:spans:read storage:bizevents:read storage:entities:read storage:buckets:read

Initial Window

How the date range is sliced before extraction starts. Each slice is independent.

  • Full range (0) — one call for everything. Best for sparse filtered queries.
  • 24h — one call per day. Good default.
  • 1h — use only for known very dense data.

Windows that exceed Max Records split automatically in half, recursively.

Max Records per Window

Cap per API call. Default 500,000. Do not exceed — Grail may reject higher values. Truncated windows split automatically.

Max Split Depth

Max halving iterations. At depth 10, min window ≈ 1.4 min from a 24h start. Increase to 15 for very dense data. Hitting max depth on a truncated window writes partial results with a warning.

Pre-flight Profiling

Before extraction, binary-searches the range with | limit 1 probes to find windows with data. Skips empty ranges entirely. Best for sparse data over long ranges (years). Each probe ≈ 10–80 MB.

Output Formats

  • JSONL — full JSON record per line. Extension: .jsonl
  • CSV — comma-separated with headers. Extension: .csv
  • Raw — timestamp + content per line. Format: 2026-04-16T10:00:00Z - <content>. Set comma-separated fields to include after the timestamp. Extension: .txt

Pause / Resume / Schedule

  • Pause — current window completes, then extraction pauses. No data loss.
  • Resume — continues from where it paused.
  • Schedule — set a future datetime in the Extract form. Job enters scheduled state and starts automatically at that time. Jobs run server-side and survive browser close.

DQL Tips

  • scanLimitGBytes:-1 is automatically added to every extraction — you don't need to type it.
  • Add bucket:{"your-bucket"} to limit scan to a specific bucket — much faster.
  • | limit N is automatically stripped during extraction.
  • Use filter over search for indexed fields.
  • Query tab uses max 100,000 records per call — use Extract for full data retrieval.
  • Click ⤢ expand next to DQL label to grow the text area.
